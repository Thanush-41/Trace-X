# Sample datasets

Generated by `npm run gen:all` (`scripts/generate.ts`); each seed produces a different population with the same planted scenarios.

| File | Contents |
|---|---|
| `customers.csv`, `accounts.csv`, `transactions.csv`, `login_events.csv`, `loan_applications.csv`, `insurance_claims.csv` | The linked dataset, one file per source system |
| `tracex.xlsx` | The same data as one workbook, one sheet per type |
| `tracex.json` | The same data as one JSON object keyed by type |
| `transactions_with_errors.csv` | 1 valid row + missing ID, impossible date, negative amount, unknown accounts, ID conflict, exact duplicate |
| `logins_alt_headers.csv` | Login events using another system's column names and `DD/MM/YYYY` dates |
| `ground_truth.json` | Expected detections (S1–S6) and lookalikes that must stay Low (L1–L4). **Evaluation only — never read by detection.** |

Planted scenarios: S1 account takeover, S2 amount outlier, S3 rapid transfers, S4 new-account drain, S5 loan ring (shared device and payout account), S6 a takeover that pays the loan ring's mule (cross-system), S7 synthetic identities, S8 phishing takeover, S9 duplicate claims paid into the ring's account, S10 one hospital stay claimed on two policies. Lookalikes: L1 family-shared tablet, L2 routine high-value business transfers, L3 forgotten password, L4 new phone, L5 couple sharing a phone, L6 claim paid to a spouse's account.
